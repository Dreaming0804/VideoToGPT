VideoToGPT 0.3.2 通用视频优先（统一工程 / Windows 测试版）
=======================================================

本次只升级「通用视频探测」，普通网页正文提取沿用 0.3.1 原逻辑；
不会改动旧的 D:\Apps\VideoToGPT，也不会自动清理 D:\VideoText。

【新增处理逻辑】
1. B站等已有视频站点仍使用成熟的 yt-dlp 平台提取器。
2. 小红书仍先检查笔记实际类型：图文保持图文，视频继续下载处理；评论默认关闭。
3. 对其他公开 HTTP/HTTPS 网页，先用 yt-dlp 查询可访问的视频格式（仅查信息，不下载）。
4. yt-dlp 没发现时，额外识别 HTML5 video/source、og:video、JSON-LD VideoObject、
   符合条件的嵌入播放器 iframe，逐个验证前四个候选源；确认后走原视频处理流程。
5. 没确认视频时，回到既有正文 / 图片提取流程。若只有无法验证的播放器链接，
   不会假装已经成功获取完整视频。
6. 视频资料包额外保存 video_source_info.json，能获得标题/简介时一并写入 page_content.txt。
7. 对静音、无音轨视频，语音识别会跳过，仍尝试获取画面并生成可分析资料。

【使用方法】
(1) 解压本工程文件夹到 D:\VideoText\ 下（也可放其他文件夹）。
(2) 保留目前已有的 D:\Apps\VideoToGPT 便携版、D:\VideoText\.venv；
    此工程优先复用现有 tools / models，不重新下载 500MB Whisper 模型。
(3) 双击「1_双击测试统一版.cmd」。
(4) 粘贴任意公开网页视频链接 / 完整分享文案，点击开始处理。
(5) 在主界面「设置输出位置」，可选择 D:\Apps\VideoToGPT\output 统一保存。
(6) 小红书评论是可选项，默认关闭；不开评论就不会弹出浏览器扫码。
(7) 需要发布独立 EXE 时，等源码版验证成功再运行「2_一键构建独立版.cmd」，
    生成到 D:\Apps\VideoToGPT_0.3.2（不覆盖以前的程序）。

【测试】
无需联网的开发回归测试（Python 已能运行时）：
  python 通用视频离线测试.py
  python 离线测试.py
测试覆盖：yt-dlp 提取器、嵌入视频候选、HTML5、OpenGraph、JSON-LD、iframe、
小红书图文不误判、评论合包、静音视频、ZIP 文件输出。
这些是离线模拟测试，真实不同网站的网络访问效果仍需实测。

【已知限制】
- 无法保证“所有网页”都可下载：登录、验证码、付费权限、DRM 加密直播、网站改版等
  都可能使解析失败。不会自动索取或上传浏览器 Cookie。
- 多媒体页面只选择第一个已确认的可用视频；视频合集/直播尚未专项处理。
- 目前的 JPG 抽帧密度与 0.3.1 相同，大 ZIP 问题留待后续优化。
- 网页正文和图片提取仍是旧版本能力；通用网页增强是下一阶段，不在本次范围。
- Windows PyInstaller 正式打包必须在 Windows 电脑执行，本 ZIP 并非预编译 EXE。

第三方依赖及许可证请见「第三方组件说明.txt」。
