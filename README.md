# VideoToGPT Android Preview
Standalone Android APK: share/paste URLs, WebView request detection and direct HTTP MP4/WebM/MOV DownloadManager transfer.
DASH/HLS are detected but **not yet downloadable in this APK**, and yt-dlp/FFmpeg are not bundled. No DRM bypass.
The full uncompiled Android project with a preliminary HLS/TS downloader is supplied separately in the chat.
GitHub Actions builds this preview debug APK from the android-preview branch. Original Windows main branch stays untouched.
